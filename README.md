# Customer Purchase Pattern Analyzer

A job-ready retail & e-commerce customer analytics project analyzing purchasing behavior, customer lifetime value, RFM segmentation, and revenue patterns.

## Tech Stack
- **Python 3.11+**
- **Pandas & NumPy**: Data cleaning, wrangling, and feature engineering
- **Scikit-learn**: Customer clustering & segmentation
- **SQLite**: Structured relational data storage & analytical queries
- **Plotly & Streamlit**: Interactive executive business intelligence dashboard
- **pytest**: Automated unit and data validation test suite

*Project setup and pipeline implementation in progress.*
